# Cyberpunk-X-Skate-mashup
Its skate inside cyberpunk, 90% Mod friendly and lightweight, Requires SKATE. downloaded. Custom loader that merges both games.
It does scans to make sure your skate and and Cyberpunk have or don't have everything needed to make the merge. 
All data produced is stored locally and its only logs. During testing it needed some bug fixing that required seeing what DLL's were blocking CyberTweak. I wanted as little data monitering as possible 
and to self contain. Everything is designed around ease of use. it has auto updater and semi-auto downloader for missing Frameworks, skate, Cyberpunk and anything else.

I'm just one guy who's never done modding or anything close to this scale, if anything is too intrusive or is stopping fun let me know so i can perfect this.

## Install

1. You need **Cyberpunk 2077** on patch 2.31 (Steam, GOG or Epic) and **skate.**, free on Steam:
   <https://store.steampowered.com/app/3354750/>, fully downloaded (Steam says *Play*).
2. Download the newest `updates/NightCityShred-Setup-<version>.exe`, run it and press **MAKE IT WORK**.
   It gets the modding tools from their authors' own pages and builds the board, tricks and sounds from your own
   copy of *skate.*: nothing from either game is in this repository.
3. Start Cyberpunk 2077 and load a save from after the opening: Rogue leaves you a board. Keep the setup: when you
   open it and it says an update is ready, press **INSTALL UPDATE** (nothing installs without that press).

Stuck? Give `NightCityShred-HELP-for-Claude.md` to Claude, or press **report** in the setup and send the file it
saves. **undo everything** in the setup takes it all out again.
